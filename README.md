# Генератор обложек квартир (1080×1080)

**Генератор онлайн:** https://platformdge.github.io/-rent-cover-generator-test/ — вставьте текст объявления и фото, скачайте картинки.

Из поста в Telegram-канале делает квадратную картинку для Instagram и Facebook в фирменном шаблоне.

На картинке:
- синяя шапка с ценой;
- плашка **EXCLUSIVE**;
- серая полоса с районом, площадью и спальнями;
- фото из поста;
- красная лента «EXCLUSIVE APARTMENT».

Плашка и лента появляются только у эксклюзивных объектов.

## Быстро, без сервера: через GitHub

1. Откройте вкладку **Actions** → **Сделать обложку** → **Run workflow**.
2. Вставьте ссылку на пост (`https://t.me/канал/123`) и нажмите **Run**.
3. Через ~30 секунд откройте запуск: картинка будет прямо на странице. Она также сохраняется в папку `covers/`.

Если что-то не нашлось в тексте (цена, район, площадь, спальни), укажите это в полях формы и запустите ещё раз. Поле «Эксклюзив» можно переключить вручную: `yes` или `no`.

> Ссылка должна вести на **публичный** канал. Пост закрытого канала (`t.me/c/...`) перешлите боту.

## Telegram-бот

```bash
pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=123:ABC python bot.py
```

Боту можно прислать ссылку на пост или **переслать сам пост**. Пересылка работает и для закрытых каналов. Бот вернёт PNG без сжатия.

Чтобы поправить поле, ответьте на картинку, например: `district=Vake price=500 bedrooms=2 exclusive=no`.

## Из командной строки

```bash
python cover.py https://t.me/канал/123
python cover.py --text post.txt --photo photo.jpg --exclusive yes
python cover.py <ссылка> --price 450 --district Sololaki --area 40 --bedrooms 1
```

## Что распознаётся

| Поле | Примеры в тексте |
|---|---|
| Цена | `370$`, `$370`, `450 USD`, `Цена: 1 200 $`, `1500 лари` → `1500 GEL` |
| Эксклюзив | `эксклюзив`, `exclusive`, `ექსკლუზიური` |
| Район | рус/англ/груз и хэштеги: `#Ваке`, `Sololaki`, `ნაძალადევი` → `VAKE` |
| Площадь | `52 кв.м`, `52 м²`, `40 m2`, `Площадь: 60` |
| Спальни | `1 bedroom`, `2 спальни`, `студия`; `2-х комнатная` → 1 BEDROOM (гостиная + спальня) |

Список районов находится в `cover.py` → `DISTRICTS`, туда легко добавить новые. Шрифт Bebas Neue скачивается автоматически при первом запуске в папку `fonts/`.
