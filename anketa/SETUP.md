# Анкета → таблица + уведомления операторам

Клиент заполняет анкету → строка появляется в Google-таблице → в Telegram-группу операторов приходит карточка заявки, которую можно переслать агенту.

## 1. Бот и группа (2 минуты)
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен**.
2. Создайте группу «Заявки» (или используйте существующую группу операторов) и добавьте туда бота.
3. Напишите в группе любое сообщение.

## 2. Таблица (3 минуты)
1. Создайте новую Google Таблицу.
2. **Расширения → Apps Script**. Удалите всё и вставьте код из `apps-script.gs`.
3. В начале кода вставьте токен в `BOT_TOKEN`. Сохраните (💾).
4. Вверху выберите функцию **findChatId** → **Выполнить** → разрешите доступ. Внизу в журнале появится ID группы (число с минусом, например `-1001234567890`). Вставьте его в `CHAT_ID`, сохраните.
5. Выберите **testSubmit** → **Выполнить**: в таблице появится лист «Заявки» с тестовой строкой, в группе — карточка.

## 3. Публикация (1 минута)
1. **Развернуть → Новое развертывание** → тип **Веб-приложение**.
2. Выполнять как: **Я**. Доступ: **Все** (Anyone).
3. **Развернуть** → скопируйте ссылку, которая заканчивается на `/exec`.
4. Пришлите её — её впишут в анкету (`ENDPOINT` в `anketa/index.html`).
